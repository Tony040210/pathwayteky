# Tính chi phí chuyến đi
## Giới thiệu
Đây là chương trình Python dùng để tính tổng chi phí của một chuyến đi chơi
-Người dùng cần nhập các thông tin:
 + Tên chuyến đi
 + Số ngày
 + số người 
 + tiền xe
 + tiền khách sạn mỗi ngày
 + Tiền xe mỗi ngày

Chương trình sẽ tính và hiển thị tổng chi phí chuyến đi

## Hướng dẫn sử dụng
Bước 1: Chuẩn bị

Cài đặt Python trên máy tính và mở file duancuoikhoa.py bằng VS Code hoặc trình soạn thảo Python.

Bước 2: Chạy chương trình

bấm run
Bước 3: Nhập thông tin

Khi chương trình yêu cầu, nhập lần lượt:

Tên chuyến đi.
Số người tham gia.
Số ngày đi.
Tiền xe.
Tiền khách sạn mỗi ngày.
Tiền ăn mỗi người mỗi ngày.

Lưu ý: Các khoản tiền nhập bằng số, không cần nhập dấu đ hoặc dấu phẩy.

Bước 4: Xem kết quả

Chương trình sẽ hiển thị:

Tên chuyến đi.
Tiền xe.
Tổng tiền khách sạn.
Tổng tiền ăn.
Tổng chi phí chuyến đi.
## Kiến thức sử dụng
-- input(): dùng để nhập dữ liệu
-- int() và float(): dùng để xử lý số
-- phép tính cộng và nhân('+', '*' )
-- print(): dùng để hiển thị kết quả
