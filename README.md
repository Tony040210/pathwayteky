# Tính chi phí chuyến đi
## Giới thiệu
Đây là chương trình Python dùng để tính tổng chi phí của một chuyến đi chơi
-Người dùng cần nhập các thông tin:
 + Tên chuyến đi
 + Số ngày
 + số người 
 + tiền xe
 + tiền khách sạn mỗi ngày
 + Tiền xe mỗi ngày

Chương trình sẽ tính và hiển thị tổng chi phí chuyến đi
## Kiến thức sử dụng
-- input(): dùng để nhập dữ liệu
-- int() và float(): dùng để xử lý số
-- phép tính cộng và nhân('+', '*' )
-- print(): dùng để hiển thị kết quả
